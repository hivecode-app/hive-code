A team of Claude Code agents you manage from your phone.

Hive Code runs on your own Linux server. A manager takes your requests, workers with names and memory do the work, and every task ends as a reviewed pull request. You step in only when the work needs you.

curl -fsSL https://raw.githubusercontent.com/hivecode-app/hive-code/main/scripts/install.sh | bash

Ubuntu or Debian with systemd, 16 GB of memory, a Claude Pro or Max plan and a GitHub account. Install guide

Every task ends as a reviewed pull request

Write to the manager the way you would write to a lead developer. Behind the scenes, each request follows the same path:

  1. A branch of its own. The worker gets a git worktree, so tasks never step on each other.
  2. Tests before the pull request. It runs the commands your project's charter lists, and fixes what fails.
  3. An independent review. A second session with no edit tools and a clean context reviews the pull request.
  4. Merge on green. It merges only with an approving review and a passing CI check.
  5. Production waits for you. Deploying asks for your GO, with the change, the risk and the way back.

It stops for you only when it must

A question the worker cannot answer alone arrives as a card with buttons. An approval to ship shows what changes and how to roll back. A login request asks once. Everything else is a message you can read when you like.

Workers remember

A worker outlives its sessions. When a session ends, the worker writes a handoff and the next shift picks it up. Decisions you make once are saved and apply to every worker, including new ones.

Your company is a repository

Roles, rules, project charters and shared memory are Markdown and YAML in ~/company. Read them, edit them, or ask the manager to change them through a pull request.

Your server, your subscription

Every worker is the real Claude Code CLI, signed in to your Claude plan. There is no API key, no backend of ours and no telemetry.

Workers have full access to the server, on purpose, so they can finish a task without asking about every command. The installer asks you to accept this first.

The server listens on localhost only. Your phone reaches it through Tailscale Funnel, a Cloudflare Tunnel or your own domain, and each device signs in with a pairing code or a passkey.
