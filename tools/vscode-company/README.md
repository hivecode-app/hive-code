# שיחה עם החברה ב-VS Code

פאנל בצד של VS Code עם אותה שיחה שיש באפליקציה עם עובד בחברה (ברירת מחדל: אביטל). כל הודעה יוצאת עם הקובץ הפתוח, השורות המסומנות וה-repo.

- **חיבור:** פעם אחת, `החברה: חיבור עם קוד התאמה`, עם קוד מהאפליקציה (הגדרות ← מכשירים). אפשר גם להשאיר טוקן מכשיר ב-`~/.config/agent-company/vscode-token`: התוסף מעביר אותו ל-SecretStorage ומוחק את הקובץ. זה מכשיר רגיל ב-hq, ואפשר לנתק אותו משם.
- **עובד אחר:** לחיצה על השם למעלה, או `company.identity` בהגדרות.
- **בנייה:** `npx @vscode/vsce package --allow-missing-repository` מתוך התיקייה. אין תלויות.
- **התקנה:** `code --install-extension company-chat-0.1.0.vsix`.
